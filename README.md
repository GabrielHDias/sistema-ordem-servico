# Sistema de Ordem de Serviço

Projeto Spring Boot gerado no [Spring Initializr](https://start.spring.io) para a atividade prática de API REST.

- Maven
- Java 17
- Spring Boot 4.1.2
- Pacote `com.exemplo.ordemservico`
- Classe principal `OrdemservicoApplication`

Dependências iniciais: Spring Web, Spring Data JPA, Validation, PostgreSQL Driver e Spring Reactive Web.
